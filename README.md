## 🎓 MSc projects — Data Science & Business Analytics, Bologna Business School

| Project | What it does | Stack |
|---|---|---|
| [**Motor Insurance Churn Prediction**](https://github.com/marialezapatag/motor-insurance-churn-prediction) | End-to-end ML model that predicts churn for an Italian motor insurer (~908K customer-years), with an [interactive dashboard](https://marialezapatag.github.io/dashboards/churn.html) | Python · scikit-learn · XGBoost · LightGBM |
| [**Reddit LLM Stock Sentiment**](https://github.com/marialezapatag/reddit-llm-stock-sentiment) | LLM pipeline that extracts stock tickers and sentiment from Reddit comments, run on the Leonardo HPC cluster, with an [interactive dashboard](https://marialezapatag.github.io/dashboards/reddit.html) | Python · LangChain · vLLM · SLURM |
| [**Customer & Marketing Analytics**](https://github.com/marialezapatag/customer-marketing-analytics) | Sentiment, topic and emoji analysis of brand social media posts, and what drives engagement, with an [interactive dashboard](https://marialezapatag.github.io/dashboards/marketing.html) | Hugging Face · VADER · statsmodels |

## 🛠️ Tools

Python · pandas · scikit-learn · Hugging Face · LangChain · Jupyter · Git
